Boba Bubble Trouble is a 3D game where players (boba bubbles) compete to escape the bubble tea cup, embarking on adventures in delicious milk tea ingredients. This game was developed in 48 hours during the 2025 Global Game Jam, using Unity as the game engine. Contributions: Game Concept, 3D Modeling, Level Design, Game Testing, Sound Design, Game development
